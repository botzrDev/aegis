# Security

GitHub's security tab reads the repository-root
[`SECURITY.md`](https://github.com/botzrDev/aegis/blob/main/SECURITY.md).
This chapter **is** that file, included verbatim rather than summarised,
so book readers get the whole policy — reporting channel, supported
versions, in-scope crates, and the Verification posture (cargo-deny,
`deny.toml`, and why Miri is not a v1 gate) — not just the disclosure
SLA.

Read the [threat model](../threat-model.md) first. Scope of protection
and scope of disclosure are one story.
